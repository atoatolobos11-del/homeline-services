🔁 How money & stock move (the important flows)

1
Customer buys

Checkout → POST /orders → record_order writes the order + items, subtracts stock, logs a sale movement — all in one safety step.

2
Order number given

The customer gets HML-YYYYMMDD-NNNN to track, cancel, or reorder later.

3
Cancel order

POST /orders/cancel → cancel_order validates (24-hr window), restores stock, logs an adjustment, marks the order cancelled.

4
Restock / edit stock

Inventory → PATCH /inventory/:id → adjust_stock updates stock and logs why.

5
Profit tracking

At sale time we freeze each item's cost_price, so revenue and profit charts are exact even if prices change later.

6
Chatbot lookup

Customer types an order number → GET /orders/:orderNumber → the bot replies with the live status (pending → shipped → delivered / cancelled).
